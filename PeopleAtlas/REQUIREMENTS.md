# 关系图谱 / People Atlas · V1 需求

## 产品

以原生卡片、网格和交互图谱维护个人的人际关系。iPhone、iPad、Mac 共用业务和本地持久化逻辑；本轮完成第一版应用，不仅是工程空壳。最低 iOS/iPadOS 17、macOS 14，SwiftUI + SwiftData + MVVM + `@Observable`。

## 第一版功能

- 人物卡片网格、统计、搜索、性别筛选、人物详情；姓名/性别/备注新增编辑，删除确认与关系级联清理。
- 11 种关系，性别过滤、双向语义、关系卡片、编辑与直接删除；选中人物只显示其关联记录。
- 智能补齐配偶家长、共同父母、兄弟姐妹；确定的补全直接保存，未知长幼确认/跳过，冲突提示，不增加远亲类型。
- 新增夫妻关系也检查双方已有的直接子女：双方互为唯一配偶且无冲突时，补齐另一方为家长及反向关系，避免无冲突家庭因先建亲子或先建夫妻而漏补。已有其他父母逐个提示跳过，不跨子女传播其他家长；多配偶跳过本次家庭补全，不递归孙辈，不回填历史数据。关闭智能补全时只保存夫妻双向关系。
- 智能确认页展示原始关系和自动补全项；长幼问题明确“A 是 B 的…”方向。每个问题必须选择或明确跳过；支持返回修改并保留输入，返回和取消均不写入任何关系。再次保存重新计算建议，旧预览不能覆盖新数据。
- 平面（圆环/等级）、星球、星云图谱；缩放、平移/旋转、暂停、全屏、选择与取消；配偶/兄弟姐妹靠近；无关系等级 -1。关系变化自动重算，保持当前模式。
- 平面圆环/等级默认显示人物姓名及合并后的双向关系称谓（例如“父亲 ↔ 女儿”）；星球/星云默认隐藏文字，人物悬停或选中、关系选中后才显示，避免破坏沉浸视图。
- 每种布局即使没有人物也保留全屏入口；Mac 监听当前窗口进入/退出全屏，按钮图标和无障碍名称在“全屏/退出全屏”之间同步变化。
- 家庭靠近不能将节点持续拉至同一点：星球保持球面形态，星云均匀铺开并按密度保持空间间距。球面投影允许前后遮挡，通过旋转/缩放查看；不虚报任意数量下均无屏幕重叠。
- 拖拽、双指缩放和选中期间暂停旋转，结束后按用户原先的播放设置恢复；减少动态效果、等级排列、可见人物不足两人时不旋转。手势中断后不残留暂停状态，缩放保持在有效边界内。
- 性别、全部关系、各关系类型筛选；总开关控制所有子项，子项可重新开启关系；真实记录不受可视筛选影响。
- SwiftData 原子保存，重启恢复，读取失败安全错误界面；正式数据接入用户私有 CloudKit 数据库，离线时继续本地使用，iCloud 恢复后自动重试，并在同一 Apple 账户的 iPhone、iPad、Mac 间同步。
- 设置页展示 iCloud 账户可用、未登录、受限、暂时不可用或无法判断等真实状态；账户可用状态不得表述为每条数据均已完成上传。测试、预览和临时文件库不连接 CloudKit。
- JSON 导出/导入备份，导入验证与替换确认，拒绝损坏或不兼容文件；备份中的姓名须已符合去首尾空白和长度规则，不静默修正非法记录；不需要旧版迁移。
- 系统/简体中文/英文语言设置；外观可选跟随系统、浅色或深色，并支持 Dynamic Type、VoiceOver、iPad/Mac 自适应导航和网格。
- 隐私说明、版本信息；真实空态、错误态、保存反馈；禁止自动生成演示人物污染正式数据。

## 后续（不属于本轮交付功能）

网页与原生数据互通、应用内账号和多人共享。iCloud 只使用系统 Apple 账户的私有 CloudKit 数据库，不提供独立登录按钮。

## 发布验收

- 功能与失败路径单元测试，关键端到端 UI 测试；真 SwiftData 持久化测试，不仅 mock。
- iPhone/iPad/Mac 可编译运行，Release 构建无错误；模拟器截图检查关键页面、大字体与深浅色。
