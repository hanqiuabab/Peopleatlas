# 人际关系网络

一个以关系图谱形式展示和维护人际关系的 Web 项目。初稿已支持人物与关系管理、图谱交互和本地持久化。

## 初稿功能

- 新增、编辑、删除人物，人物包含姓名与性别。
- 新增、编辑、删除父亲、母亲、丈夫、妻子、儿子、女儿、哥哥、姐姐、弟弟、妹妹、同事关系。
- 新增关系时自动补齐反向关系，修改或删除时同步维护两个方向。
- 删除关系无需二次确认，点击即删除该关系及其反向关系；人物删除仍保留级联删除确认。
- 新增关系默认开启智能家庭补全：添加子女时补齐另一位家长，添加兄弟姐妹时补齐已知父母；全部确定时直接保存，仅长幼未知或存在冲突时弹窗确认。已有关系不重复添加，长幼未知可逐项选择或跳过。
- 图谱将一对正反关系合并为一条双向语义线，避免两条连线完全重叠。
- 拦截空姓名、自关联、人物引用错误和重复关系。
- 删除人物前提示并级联删除相关关系。
- SVG 图谱支持节点拖拽、画布平移、滚轮/按钮缩放和选中联动。
- 平面图谱支持按人物等级自动排列：父母上一层、子女下一层，配偶、兄弟姐妹和同事保持同层；关系增删改后会自动重新排列，也可一键恢复自由排列。
- 等级排列中，没有任何关系的人物单独位于等级 -1；新增关系或删除最后一条关系后自动更新等级，隐藏连线不影响等级。
- 平面图谱默认圆环排列并自动旋转，右下角可暂停/继续、退出圆环或切换等级排列；人物增删和性别筛选后自动均分圆周，暂停时仍会更新人物布局。选中人物或关系时暂停，少于两人或系统要求减少动态效果时不自动旋转。
- 三种模式按关系亲疏优化距离：夫妻优先相邻，其次兄弟姐妹与父母子女，同事为较弱参考。圆环按家庭排序，等级模式优化同层顺序，星球和星云拉近亲近人物并保留间距，星云中的不同家庭分区分布。增删改关系会更新布局，隐藏连线不会打乱排列；自由模式保留手动拖动的位置，复位可重新自动排列。复杂家庭按优先级尽量靠近，不保证所有亲属同时相邻。
- 平面、星球和星云模式均可通过右下角按钮全屏显示完整图谱画布，并可通过按钮或 Esc 退出。
- 选中人物后可拖动节点右侧的“＋”句柄到另一人物，松手后直接在弹窗中绑定关系。
- 选中人物时，右侧关系记录会自动过滤为该人物参与的关系。
- 顶部可在“平面”“星球”和“星云”三种图谱风格间切换；星球模式提供球体节点投影与旋转，星云模式提供自由云团布局、按连接度变化的发光节点、多层关系丝线和宇宙粒子氛围。
- 三种模式右上角均可按性别、全部关系或任一关系类型切换显示内容，切换模式时保留筛选状态。
- 一级“关系”按钮可一键开启或关闭全部二级关系类型；一级关闭后单独开启任一类型，会立即恢复该类型的关系连线。
- 星球人物节点默认隐藏姓名，鼠标悬停、键盘聚焦或点击选中后显示；选中轮廓仅环绕球体，姓名保持在轮廓之外。
- 星球模式选中人物或关系时会自动暂停旋转，再次点击同一目标或点击空白取消选择后自动继续。
- 星球关系线默认隐藏名称，选中后才显示，并以线条发光代替方形选中框。
- 星球模式选中人物时只保留与该人物有关的关系线，取消选择后恢复全部连线。
- 平面和星球关系线不显示端点箭头；平面关系选中时仅高亮线条与标签，不显示方形外围框。
- 星云模式支持自动缓慢漂移、暂停、拖拽探索、滚轮缩放和重置视角；选中人物后只保留相关关系丝线，节点或关系被选中时自动暂停。
- 使用浏览器 localStorage 保存数据，刷新页面后仍可恢复。
- 提供桌面端和移动端响应式布局。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与类型检查：

```bash
npm run typecheck
npm test
npm run build
```

## 数据说明

初稿数据只保存在当前浏览器中，不会上传到服务器。清除该站点的浏览器数据会同时清除图谱内容。

## 智能添加关系

在“添加关系”中保留勾选“智能补齐家庭关系”。例如 A、B 是夫妻，C 是他们的儿子：

- 添加“D 是 A 的女儿”，预览会补齐“D 是 B 的女儿”，并询问 D 是 C 的姐姐还是妹妹。
- 添加“D 是 C 的姐姐”，自动补齐 D 与 A、B 的亲子关系；若无其他待确认关系或冲突，直接保存，不再弹窗。
- 对每项未知长幼关系选择称谓或“暂不添加”，然后点击“确认并添加”；所有关系均同时维护反向关系。
- 需要确认时，“返回修改”保留原始输入，“取消”不保存任何内容。无需补全时可在提交前关闭该选项。

当前按唯一配偶为另一位家长、兄弟姐妹共享已知父母的规则生成建议，并非判断真实血缘。重组家庭可在提交前关闭智能补全后单独添加；多个配偶、父母候选冲突等情况会提示跳过。补全只发生在新增亲子或兄弟姐妹关系时，编辑/删除不会连带推导或删除其他家庭关系。
